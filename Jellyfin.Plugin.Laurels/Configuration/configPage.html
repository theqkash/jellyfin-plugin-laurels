Ratings written into Jellyfin

Community rating is the star value (0–10); critic rating is the tomato/percentage value (0–100). The fallback is used when the primary source has no rating.
Titles with a missing source are retried after 12 hours regardless.

Web interface

Requires the File Transformation plugin (repository: https://www.iamparadox.dev/jellyfin/plugins/manifest.json). Restart Jellyfin and reload the browser after changing these.

Awards

Known keys: oscars, golden_globes, bafta, cannes, berlin, venice, emmys, cesar, goya, european_film_awards, polish_film_awards, sundance, annie, saturn, razzies.
Changing the language re-fetches category labels on the next awards refresh.

Awards library

A separate library of type "Collections" that holds one collection per award: Oscar winners, Oscar nominees, Cannes winners… It shows up next to your other libraries in every client. Members are synced after each awards refresh.
Empty = winners of every enabled family plus Oscar nominees.

Home screen sections

Requires the Home Screen Sections plugin. Each user picks the rows they want under Modular Home. Rows are computed on the fly; when the awards library is on, the row title links to the matching collection.
Keys: winners:<family>, nominees:<family>, top:<source> (imdb, filmweb, metacritic, tomatoes…), award_winners, award_nominees. Takes effect after a restart.
